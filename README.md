# ☕ Landing Page Kedai Kopi Nostalgia

Website landing page responsif untuk usaha kedai kopi lokal yang dibuat menggunakan HTML5 dan CSS3.

## 🚀 Fitur Utama
- Navigasi yang bersih dan responsif
- Seksi *Hero* menarik dengan panggilan aksi (*Call to Action*)
- Kartu daftar menu favorit beserta harga
- Integrasi pemesanan langsung ke WhatsApp

Kunjungi websitenya secara langsung di: [https://lusiasiftiana-glitch.github.io/landing-page-kopi](https://lusiasiftiana-glitch.github.io/landing-page-kopi)

## 🛠️ Teknologi yang Digunakan
- HTML5
- CSS3
